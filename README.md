# MAP OPS

다층 구조 게임(레인보우 식스 시즈 등) 맵을 직접 올린 단면도로 보는 개인용 웹앱.
한 층에서 가리킨 지점이 다른 층의 같은 물리적 위치에 바로 대응된다. 설계는 [MAPOPS-spec.md](MAPOPS-spec.md)를 볼 것.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 단위 테스트
npm run build      # dist/ 에 정적 파일 생성(GitHub Pages 등에 그대로 올리면 됨)
```

개발 모드의 맵 목록에는 "샘플 맵 생성 (개발용)" 버튼이 있다(배포 빌드에는 없음).

## 사용법

1. **맵 추가** — 이름 → 층 이미지 업로드(여러 장 가능, 끌어다 놓기 가능) → ★로 기준층 지정, ⠿로 순서 변경.
2. **정렬** — 3-0 화면 맞춤 → 층마다 3-1 위치(드래그·방향키) → 3-2 배율(**Ctrl+휠**, Shift 동시: 미세). 휠은 화면 확대, 오른쪽 드래그는 화면 이동. 아래 비교 격자로 전체를 확인.
3. **사용** — 클릭: 위치 확인(십자선) · 드래그: 이동 · 휠: 확대. "N층에서 보기", "+ 여기에 마커 추가"(이 층만 / 여러 층 관통), 2단 비교, 이전 층 겹쳐보기.
4. **공유** — 맵 화면의 "공유" → "공유 시작" → 링크를 친구에게 보낸다. 친구가 링크를 열고 "참여"하면 실시간으로 함께 바뀐다. 서버 없이 브라우저끼리 직접 연결하므로 양쪽이 동시에 접속해 있어야 한다.
5. **백업** — 맵 카드 `⋯` → 내보내기(.mapops), 목록 상단 "가져오기".

데이터는 브라우저(IndexedDB)에만 저장된다. 브라우저 데이터를 지우면 사라지니 중요한 맵은 내보내기로 백업할 것.

## 구조

| 경로 | 내용 |
|---|---|
| `src/geometry.ts` | 좌표 변환(층 닮음변환, 뷰 변환, 기준층 변경·이미지 교체) |
| `src/mapOps.ts` | 맵 단위 연산(기준층 변경, 층 삭제, 편집 병합) |
| `src/store/` | Yjs 문서 ↔ 모델, IndexedDB 저장, 이미지 Blob 저장소, .mapops |
| `src/wizard/` | 맵 추가·편집 마법사(층 목록, 정렬) |
| `src/viewer/` | 사용 화면(패널, 마커, 십자선) |
| `src/share/` | 실시간 공유(Trystero + Yjs + awareness) |
| `reference/` | 원래 프로토타입과 v1 명세서 |

## 라이선스 고지

사용 라이브러리: React, Yjs, y-indexeddb, y-protocols, Trystero (모두 MIT). 레퍼런스로 참고한 r6maps(capajon/r6maps)도 MIT이며, 맵 이미지는 앱에 포함하지 않는다.
